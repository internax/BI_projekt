- Zpracování dat je souboru data_processing.ipynb
- Data k vykreslení grafů jsou ve složce data, takže by grafy měly jít upravovat i bez původní datové sady
- Ne všechny grafy jsou do reportu, některé jsou spíš pro zajímavost
- Grafy jsou uloženy ve složce plots.
- Závěrečná zpráva je ve složce sablona/main.pdf

# Struktura skriptu

- Jako nástroj jsme si vybrali python s tím, že pro větší přehlednost jsme řešení vyhotovili v python notebooku. 
- Z knihoven jsme využili klasické knihovny pro práci s daty jako jsou `pandas`, `matplotlib` nebo `numpy`
- Notebook je strukturován tak, že v  .md poznámce je vždy vypsáno teoretické pozadí ke kódu a pak následuje samotný kód.
- Protože jsou poznámky dostatečně vysvětlující, není třeba kód dále popisovat.
